Requirements:
Events directory

Run UTIDE.ipynb to create gzXXYYYY{NO_NODAL}.txt, where XX is the station number
and YYYY is the year. These text files contain the same data as in tables 1 and 
S3.

NO_NODAL refers to no nodal corrections.
